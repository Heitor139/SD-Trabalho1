# Cliente JavaScript

Projeto cliente independente do servidor Java. Requer Node.js com fetch disponível.

- cliente-api.js: operações da API HTTP/JSON.
- main.js: entrada do console.
- package.json: configuração do projeto, sem dependências externas.

O transporte previsto utiliza fetch e JSON. O cliente terá as mesmas operações do cliente Python e poderá publicar, assinar e consultar eventos.

Os métodos ainda não estão implementados. A API do servidor também precisa ser implementada antes de executar o cliente.
